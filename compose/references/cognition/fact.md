# Fact

What a fact is and what it is not. Facts are the substance every compose
producer writes and every consumer reads.

## Definition

1. A fact is one stage-local statement of what is true for the current
   slice.
2. Facts stay at decision level: goals, boundaries, exclusions, decisions,
   invariants, phases. Wording, layout, and chapter placement are not
   facts.
3. A fact carries no presentation. Each consumer rebuilds how it appears;
   nothing about appearance is stored on the fact.

## Read source

1. Within a revision, the slice fact set is the only substance read source.
2. Across stages, the delivered document is the authority. The fact set is
   a process artifact, not a delivery package.

## Judgment

1. What the fact set states is settled substance for this slice.
2. What the fact set does not state is unknown for this slice — neither
   false nor decided elsewhere.
