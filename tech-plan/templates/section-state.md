# Section Provenance Legend

Markers embedded in `tech-doc.md`, immediately above each section heading.

## Format

```markdown
<!-- §state:I -->
## §3 Implementation Plan

<!-- §state:N/A-c evidence:"decision-doc §Scope: 'no API contract changes'" -->
## §7 API Contract Changes
```

## States

| State   | Meaning                           | Writer              |
|---------|-----------------------------------|---------------------|
| `X`     | Initial placeholder (transient)   | Template init       |
| `I`     | Seeded from decision-doc          | initializing-runner |
| `P`     | AI-generated by generating-runner | generating-runner   |
| `N/A-s` | Excluded by change type           | scoping-runner      |
| `N/A-c` | Excluded by decision-doc content  | scoping-runner      |
| `U`     | User-authored in free-edit        | User / AI assist    |

## Rules

1. Once written, `§state:` comments are immutable — do not edit or delete unless the entire section is removed.
2. Only the designated writer may set each state.
3. AI adding sections in free-edit must prefix `<!-- §state:U -->`.
4. No `X` should remain after all three sub-agents complete.
